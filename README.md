# ShopAgent: AI-Powered Multi-Vendor E-Commerce Platform

ShopAgent is a production-grade multi-vendor e-commerce platform powered by an autonomous multi-agent AI system.

## Architecture Overview

- **`frontend/`**: React + Vite client (Storefront, Seller Dashboard, Admin Dashboard, AI Chat UI).
- **`server/`**: Node.js + Express REST API (Auth, RBAC, Catalog CRUD, Multi-vendor Cart & Atomic Orders, MongoDB Mongoose models).
- **`ai-service/`**: Python + FastAPI Multi-Agent Service (Orchestrator, Product Agent, Comparison Agent, Recommendation Agent, Seller Assistant Agent).
- **`docs/`**: Architectural blueprints, API specifications, and database schema documentation.

## Getting Started

Refer to individual subsystem directories (`frontend/`, `server/`, `ai-service/`) and `docs/` for setup and run instructions.
